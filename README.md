# Ratio Tables - A CRA Lesson

**Live lesson:** https://ratio-tables-lesson.vercel.app

A short interactive lesson that teaches ratio tables and the constant of proportionality
to a 6th-7th grade learner, built using the Concrete-Representational-Abstract (CRA)
instructional framework with pattern block manipulatives.

## Pedagogical rationale

The lesson is anchored to the structural 2:1 relationship between yellow hexagon and
red trapezoid pattern blocks: two trapezoids physically reassemble into one hexagon.
Across five steps, the learner moves from manipulating shapes, to filling a ratio
table that gradually replaces shapes with numerals, to using the constant of
proportionality (2/1) to solve scaled problems - first forward, then in reverse.
The arc ends with inverse application as evidence of transfer, not just recall.

## Run locally

```bash
git clone [repo-url]
cd ratio-tables-lesson
npm install
npm run dev
```

## Stack

Vite, React, TypeScript, Tailwind, Framer Motion. Single-page, no backend, no persistence.
